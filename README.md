# TEKPC – Cửa Hàng Máy Tính & Setup Công Nghệ Trực Tuyến

Website thương mại điện tử chuyên cung cấp máy bộ Gaming, PC đồ họa, Laptop và linh kiện máy tính chính hãng, tích hợp trợ lý AI thông minh (AI Chatbot tư vấn cấu hình, AI Visual Search nhận diện linh kiện, và công cụ PC Builder).

---

## 🌟 Tính Năng Nổi Bật

- **Bộ Sưu Tập Sản Phẩm**: Danh mục máy bộ Gaming, PC Custom nước, PC Văn phòng, Màn hình 2K/4K, Laptop và phụ kiện.
- **AI Hardware Chatbot**: Tư vấn cấu hình máy tính theo ngân sách, mục đích sử dụng và giải đáp kỹ thuật 24/7.
- **AI Visual Search**: Tìm kiếm linh kiện, máy tính thông qua nhận diện hình ảnh phần cứng bằng thị giác máy tính.
- **Công Cụ Xây Dựng Cấu Hình PC (PC Builder)**: Tùy biến cấu hình máy theo từng mức ngân sách với thông tin FPS và hiệu năng thời gian thực.
- **Giỏ Hàng & Thanh Toán Trực Tuyến**: Lưu trữ trạng thái đơn hàng (Local Storage), áp mã giảm giá và tính toán tổng tiền tự động.
- **Hệ Thống Showroom & Tra Cứu Đơn Hàng**: Tra cứu lịch sử đơn hàng và địa chỉ showroom bảo hành.

---

## 🛠️ Công Nghệ Sử Dụng

- **Frontend Core**: [React 19](https://react.dev/) + [Vite](https://vite.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Biểu Tượng & Animation**: [Lucide React](https://lucide.dev/), [Motion](https://motion.dev/), [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti)
- **Deployment**: Tối ưu hóa sẵn sàng triển khai trên [Vercel](https://vercel.com), [Netlify](https://netlify.com) và [GitHub Pages](https://pages.github.com/).

## 🚀 Hướng Dẫn Cài Đặt & Chạy Cục Bộ

1. **Clone repository về máy**:
   ```bash
   git clone https://github.com/your-username/ai-electro-store.git
   cd ai-electro-store
   ```

2. **Cài đặt thư viện**:
   ```bash
   npm install
   ```

3. **Chạy máy chủ phát triển (Dev Server)**:
   ```bash
   npm run dev
   ```
   Mở trình duyệt truy cập: `http://localhost:5173`

4. **Đóng gói phiên bản Production**:
   ```bash
   npm run build
   ```
   Thư mục đầu ra được tạo tại `./dist`.
